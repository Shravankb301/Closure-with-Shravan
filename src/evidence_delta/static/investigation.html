Why this exists

Evidence overload is only half the problem.

Search can help an investigator find a record. It does not keep every timeline, finding, and handoff trustworthy after that record is corrected, supplemented, or withdrawn. Evidence Delta treats those downstream products as governed case state.

The workflow gap

Case analysis drifts when the source set changes.

A correction can invalidate a timeline, clear a conflict, or change the next investigative action. Manual cross-checking is slow and makes stale work hard to detect.

The product bet

Treat derived work like versioned operational data.

Every evidence mutation becomes a numbered revision. The system records its impact, rebuilds only affected artifacts, and preserves the exact inputs behind each output.

The investigator outcome

Know what changed, why it changed, and what needs review.

The user gets an attention queue, source-linked reasoning, reversible corrections, and a case handoff that another reviewer can safely continue.

Real integration boundary

Inputs and outputs

The interface is one client of an API and worker system.

Structured evidence intake

Idempotent document and assertion writes through POST /cases/{id}/documents.

Public artifact connector

GET /cases/{id}/source-acquisitions exposes retrieval, redirect, fingerprint, extraction, and source-span verification state for every official URL.

OCR and browser resolution

Scanned PDFs use the configured OCR adapter. Challenge pages can be downloaded through an approved browser and imported through POST /cases/{id}/source-acquisitions/{document_id}/imports.

Artifact custody

Exact returned bytes are stored by SHA-256 in a content-addressed vault. Every fetch or reviewer import appends a linked custody event whose hash is verified on read.

Cited case search

GET /cases/{id}/search?q= ranks active assertions and returns exact source excerpts and locators without generating an answer.

Evidence graph service

GET /cases/{id}/evidence-graph maps active ledger rows into source, assertion, entity, and finding nodes with labeled relationships. The browser renders that contract instead of inventing the graph.

Review-gated extraction

POST /extract proposes cited assertions. A human must confirm before the ledger changes.

Portable case packet

Sources, findings, history, operational proof, and artifact lineage export as one durable JSON handoff.

API and worker deployment

Independent processes coordinate through PostgreSQL leases, fencing tokens, and immutable version records.

The public web connector runs live against allowlisted DOJ and FBI URLs. It does not authenticate into agency systems. Customer connectors would use the same ingestion contract without bypassing the evidence ledger.

Contradiction candidates
